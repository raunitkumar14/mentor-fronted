## Direction contract

THESIS: Strip the soft-shadow SaaS-card default; let type weight, a hairline rule, and one accent color carry all hierarchy — refuses the boxed-card dashboard this category always ships.

OWN-WORLD: Near-black ink on white ground (near-white ink on near-black in dark mode); exactly ink + 2 grays + 1 restrained accent, no incidental fifth color anywhere including the histogram fill; zero shadows, 1px hairline dividers only, radius capped near 6px; tabular/mono numerals for every metric, system sans for labels; each KPI keeps a fixed grid position across reloads so a manager builds spatial memory of where each figure lives.

STORY: A manager picks an owner and a range and reads, in one glance, whether that agent's leads are being worked — no card-hunting, hairlines and type weight alone do the telling.
